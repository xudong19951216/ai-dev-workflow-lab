## 给审查者的交接消息

“请读取 PR 及其关联 Issue、AGENTS.md 和设计文档，先独立审查当前 Head SHA，再对照另一位审查者意见。不要修改代码。按审查模板报告问题和证据、检查范围及局限，并注明最新 SHA。若读取后 Head 已变化，重新核对后再给最终结论。”

## 给 WorkBuddy 的修复消息

“请读取 PR 中汇总的修复清单，确认当前 Head SHA。逐条修复并运行相关测试；每条说明修复提交与结果。有异议请给证据，不擅自忽略。需要修改架构或范围时先提出变更。提交后返回新 SHA，等待复审，不自行合并。”
